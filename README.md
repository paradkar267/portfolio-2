# Yash Paradkar — Full-Stack Developer & AI Systems Builder

A high-performance, single-page 3D interactive portfolio featuring custom Three.js ribbons, responsive layouts, sleek typography, dynamic interactive project showcases, and a touch-optimized mobile navigation drawer.

![Portfolio Preview](portfolio-asset-pack/portraits/yash-portrait-transparent.png)

---

## ✨ Features

- **3D Crystal & Metallic Ribbon Atmosphere**: Built with Three.js WebGL rendering glowing lime ribbons and dynamic camera orbit reactions.
- **5 Seamless Sections**:
  - **Home (Hero)**: High-impact typography, hero portrait, social anchors, and quick-action CTAs.
  - **About**: Engineering background (GH Raisoni University, Bizleap Technologies internship), pillars, and quick facts.
  - **Skills & Craft**: Frontend, Backend, and Applied AI tooling with interactive hover highlights.
  - **Selected Work**: Featured projects including **Jewel-Bot AI**, **FinFlow**, and **DevPulse** with credentials and live demo links.
  - **Contact**: Interactive conversation card, direct communication channels, and working contact form feedback.
- **Fully Responsive & Touch-Optimized**:
  - Custom animated hamburger menu and frosted glass mobile drawer.
  - Zero horizontal overflow (`overflow-x: clip`).
  - Fluid typography with CSS `clamp()`.
- **Vanilla Performance**:
  - Clean HTML5, Vanilla CSS3 tokens, and vanilla modern JavaScript (ES6+).
  - No bloated dependencies or heavy CSS frameworks.

---

## 🛠️ Tech Stack

- **Markup & Architecture**: HTML5 Semantic Elements
- **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid, Flexbox)
- **3D Graphics**: Three.js (WebGL)
- **Logic & Interactions**: Modern JavaScript (ES6+)
- **Typography**: Bebas Neue, Outfit, Inter (Google Fonts)

---

## 🚀 Getting Started

To run locally:

```bash
# Clone the repository
git clone git@github.com:paradkar267/portfolio.git
cd portfolio

# Run with any static server, e.g.:
python -m http.server 5500
# or
npx serve .
```

Open `http://localhost:5500` in your browser.
