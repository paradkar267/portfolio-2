## Use the assets

- Open `preview.html` after extracting the ZIP to browse the images and open individual files.
- Place the backgrounds behind live HTML text, buttons, navigation and forms. The backgrounds have no embedded portfolio UI.
- Use `portraits/yash-portrait-transparent.png` as a separate image layer on the Home hero. Its background is genuinely transparent.
- Use `object-fit: contain` for the portrait to preserve the full face. Background images can use `cover`; adjust background positioning for mobile so their decorative objects do not compete with text.
- The white YP logo is designed for a dark background and contains transparent padding.
- Palette: charcoal #0C1012, warm white #F5F5EC, lime #C9FB55.
- These are static raster images. They can be moved or tilted with CSS, but they are not editable 3D models or animation files.

## Source and accuracy

These assets were recreated with image generation from the supplied portfolio mockups. They are not original layered design files or pixel-exact extractions. Replace them with actual project screenshots when publishing a portfolio that documents the finished work. The portrait is a regenerated version based on the provided photo.

Image generation mode: built-in tool. Source instructions: clean background reconstruction with all interface elements removed; identity-preserving portrait separation; transparent YP monogram; standalone conceptual project previews. Original PNG output is preserved without resizing or recompression.
